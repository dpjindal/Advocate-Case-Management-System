# Advocate-Case-Management-System
This site code is for advocates to maitain their daily case diary, manage cases and clients with their contacts.
To install on local host like xampp: create a folder of your chocie in htdocs folder and copy all files in this folder. Write the index.php file name in the path of your local server and see result.
On the live hosting server, create a folder of your choice name in the root folder of your hosting site and copy all these files in that folder. 
Before star, create a database and tables as per attached .sql file and a full fledged working site is ready for you.
